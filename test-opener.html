Mock Opener Application for Standalone QR Scanner

1. Test Opener Window Communication

Click the button below to launch the standalone scanner using window.open('index.html'). When a valid ticket QR is scanned, the scanner will post the message back to this window:

{ type: "TCC_QR_SCANNED", token: "TCCQR-..." }

2. Received Token Log

Tokens received via window.addEventListener('message') will appear below in real-time:

Waiting for scanner messages... No tokens scanned yet. Open the scanner to test.

3. Sample Test Tokens & Format Rules

The scanner strictly requires TCCQR- followed by exactly 32 hexadecimal characters (38 characters total):

✔ Valid Ticket Token A (38 chars):
TCCQR-a1b2c3d4e5f60718293a4b5c6d7e8f90
✔ Valid Ticket Token B (38 chars):
TCCQR-8f9e0a1b2c3d4e5f6a7b8c9d0e1f2a3b
✘ Invalid Format (Non-championship QR):
https://example.com/other-ticket
✘ Invalid Length (Too short):
TCCQR-12345

Tip: To scan these samples with your phone or webcam, paste any sample token into a free online QR generator (or your phone's screen) and aim the scanner camera at it.
